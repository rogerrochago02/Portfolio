# Portfólio

Portfólio pessoal com apresentação, habilidades e projetos de desenvolvimento web.

**Demo:** https://rogerrochago02.github.io/Portfolio/

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página inicial e apresentação
- `projetos.html` — página com os projetos
- `style.css` — estilos da página inicial
- `projetos.css` — estilos da página de projetos

## Como executar

```bash
git clone https://github.com/rogerrochago02/Portfolio.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
