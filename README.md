# Portfólio — Roger Rocha

Portfólio pessoal de QA Júnior com foco em testes manuais, automação E2E com Playwright e projetos de desenvolvimento web.

**Demo:** https://rogerrochago02.github.io/Portfolio/

## Destaques

- Case de QA com 17 bugs documentados e relatório em PDF
- Automação E2E do Stock Bar com Playwright, TypeScript e GitHub Actions
- Projetos web responsivos com HTML5, CSS3 e JavaScript

## Tecnologias

- HTML5, CSS3 e JavaScript
- Playwright e TypeScript
- Git, GitHub e GitHub Actions

## Estrutura

- `index.html` — página única com apresentação, case de QA, projetos e contato
- `style.css` — estilos do site
- `script.js` — menu mobile, animações de entrada e cópia de e-mail
- `docs/relatorio-bugs-qa-project-template.pdf` — relatório de bugs do case de QA
- `imagens/projetos/` — screenshots dos projetos
- `projetos.html` — redireciona para a seção de projetos da página inicial

## Como executar

```bash
git clone https://github.com/rogerrochago02/Portfolio.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
